## About Me

I build production machine learning systems — the kind that make a live decision, not just a notebook that scores well. Currently a **Data Scientist / ML Engineer at Fenix Commerce** (Noida, India), where I own a causal uplift-modeling system, ship forecasting models to production, and work on applied GenAI. B.Tech in Computer Science at **LNMIIT, Jaipur** (2026), with a research internship at **King's College London** on multimodal deep learning.

- **Applied GenAI & RAG** — retrieval systems judged by a real evaluation harness, not by how confident the answer sounds.
- **Computer Vision** — detection pipelines shipped as working applications, not just a training script.

## Featured Projects

**[RAG over SEC 10-K Filings](https://github.com/rajatsatonkar/agentic_rag_sec_filings)** · `Python` `Qdrant` `FastAPI` `Docker` `RAGAS`
Hybrid RAG system over 22K+ SEC filing chunks (narrative + XBRL), with a custom RAGAS evaluation harness that measured 0.91 faithfulness — and, more usefully, proved *retrieval* was the actual bottleneck, not generation. Deployed as a Dockerized FastAPI service.

**[ANPR Smart Gate Entry System](https://github.com/rajatsatonkar/ANPR_COMPUTER_VISION)** · `Python` `YOLOv8` `EasyOCR` `FastAPI` `Streamlit`
Real-time vehicle and license-plate recognition for automated gate access: YOLOv8 detection, SORT tracking, OCR, and a SQLite-backed authorization system behind a FastAPI API and a Streamlit operator UI. My final-year thesis, tested on 1,385 images.

**[Loan Approval: Supervised Learning vs. Offline RL](https://github.com/rajatsatonkar/Lending_Club_Loan_Data_Project_ANN_RL)** · `Python` `PyTorch` `d3rlpy` `SHAP`
Compared a supervised default-risk classifier against an offline reinforcement-learning policy (Conservative Q-Learning) for loan approval, framed as a one-step contextual bandit and evaluated by Estimated Policy Value.
